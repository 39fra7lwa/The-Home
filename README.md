# The Home — Anime discovery website template

## Run locally
Open `index.html` in a browser. No build step is required.

## Free hosting (recommended: Cloudflare Pages)
1. Create a free Cloudflare account: https://dash.cloudflare.com/sign-up
2. Open Workers & Pages, then Create application → Pages.
3. Choose Direct Upload (or connect a Git repository).
4. Upload the contents of this folder (index.html, style.css, script.js).
5. Deploy. Cloudflare gives you a free `*.pages.dev` address and HTTPS.

## Customize
- Edit `anime` and `featured` arrays in `script.js` to change titles, images, descriptions, genres and ratings.
- Replace image URLs with images you have permission to use.
- The player button is a placeholder. Add an authorized embed URL/player integration before publishing.
- This is a static front-end template. Accounts, favorites synced across devices, admin dashboard, database and server-side video delivery need a backend.

## Important
Hosting a website does not grant rights to stream anime. Only embed or distribute videos you own, have licensed, or are authorized to use. Do not upload copyrighted episodes without permission.
